# Dadinho
O Dadinho é um bot co-host autônomo criado para o YouTube. Com Inteligência Artificial e Visão Computacional, ele assiste à sua live, entende a ação na tela e interage no chat de forma orgânica em PT-BR. Extremamente otimizado, ele roda de PCs fracos a setups gamers, agindo como um espectador real
